## 🛠️ Hands-On Projects

### 1. Network Interface & TCP/IP Diagnostics Lab
* **Objective:** Verify network adapter mapping, VirtualBox host-only network isolation, and TCP/IP stack integrity.
* **Key Commands & Utilities:** `ipconfig /all`, `ping 127.0.0.1`, `tracert`, `nslookup`
* **Key Findings:** Confirmed loopback interface functionality (`TTL=128`, 0% packet loss) and verified VirtualBox network adapter segmentation (`192.168.56.1/24`).

### 2. Linux Host Security Audit & System Hardening
* **Objective:** Conduct network service reconnaissance and execute baseline security controls on a target host environment.
* **Key Commands & Utilities:** `nmap`, `ufw`, `systemctl`, Linux CLI
* **Key Findings:** Identified active network services, terminated unneeded background daemons, and configured baseline firewall parameters to preserve host integrity.
